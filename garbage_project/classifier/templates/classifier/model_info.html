ABOUT THE MODEL

How Does Our Waste Classifier Work?

Our waste classification system uses deep learning and computer vision to identify different categories of waste from an uploaded image.

EfficientNetB0

Transfer Learning Based Image Classification

01. Model Overview

The classification system is built using EfficientNetB0, a convolutional neural network (CNN) architecture originally trained on ImageNet.

Instead of training an entire neural network from scratch, we use transfer learning. The pretrained EfficientNetB0 network acts as a feature extractor, while additional dense layers are trained to classify waste images into our required categories.

Why EfficientNetB0?

EfficientNet uses a compound scaling approach to balance network depth, width, and input resolution. EfficientNetB0 provides a relatively lightweight architecture while maintaining strong image classification capabilities.

03. Image Preprocessing

Before an image is passed to the neural network, it undergoes several preprocessing operations.

1

Image Upload

The user uploads an image through the Django web interface.

2

Color Conversion

The image is converted from OpenCV's BGR representation to RGB.

3

Resizing

The image is resized to 224 × 224 pixels to match the model's input dimensions.

4

Tensor Conversion

The image is converted to float32 and a batch dimension is added.

5

Prediction

The processed image is passed to the trained model for classification.

Important preprocessing detail:

The inference pipeline retains pixel values in the 0–255 range. We do not divide the image by 255 because the EfficientNetB0 implementation includes its own input rescaling.

05. Training Methodology

The model was trained using a two-stage transfer learning approach.

STAGE 01

Feature Extraction

Initially, the pretrained EfficientNetB0 backbone is frozen. Only the custom classification head is trained.

  • Pretrained ImageNet weights
  • Frozen EfficientNetB0 layers
  • Adam optimizer
  • Learning rate: 0.0003
  • Sparse categorical crossentropy loss
STAGE 02

Fine-Tuning

After training the classification head, the last 40 layers of EfficientNetB0 are unfrozen to allow the model to learn more task-specific features.

  • Fine-tune last 40 backbone layers
  • Batch Normalization layers remain frozen
  • Adam optimizer
  • Learning rate: 0.00001
  • Sparse categorical crossentropy loss

Regularization and Augmentation

Random Flip

Introduces horizontal variations.

Random Rotation

Rotates images by small random angles.

Random Zoom

Introduces scale variations.

Random Contrast

Changes image contrast during training.

Dropout

Reduces over-reliance on individual neurons.

Class Weights

Helps account for differences in class frequency.

06. Classification Output

The final layer uses Softmax activation to produce a probability distribution across the six classes.

Example:

Suppose the model produces the following probabilities for an uploaded image:

Cardboard 5%
Glass 2%
Metal 3%
Paper 82%
Plastic 6%
Trash 2%

In this hypothetical example, Paper has the highest predicted probability, so it is selected as the predicted class.

Note:

The Softmax probability represents the model's confidence score, not a guarantee that the classification is correct.
